## Overview

Luxdata es un sistema de gestión hotelera completo diseñado para optimizar las operaciones diarias de un hotel: desde la reserva inicial hasta el checkout y la facturación.

## Problema

La gestión manual de habitaciones generaba conflictos de reservas, errores en facturación y falta de visibilidad sobre la ocupación real. El equipo operativo necesitaba una herramienta unificada.

## Solución

Plataforma web con módulos integrados para cada área operativa:

- **Reservas**: creación, modificación y cancelación con verificación de disponibilidad en tiempo real
- **Check-in / Check-out**: flujo guiado con registro de huéspedes
- **Facturación**: generación de facturas con servicios adicionales
- **Bloqueo de habitaciones**: mantenimiento, limpieza y estados especiales
- **Dashboards**: ocupación actual, ingresos del período, distribución geográfica de clientes

## Métricas destacadas

- 82 habitaciones gestionadas
- 64 habitaciones activas en temporada alta
- Incremento del 18% en ingresos reportados vs. sistema anterior
- Check-in de 12 huéspedes simultáneos sin conflictos

## Stack técnico

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express
- **Base de datos**: MySQL con transacciones para consistencia de reservas
